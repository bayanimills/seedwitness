# Support

SeedWitness is an open-source project maintained on a best-effort basis. There
is no guarantee of individual support, recovery assistance, or suitability for
holding funds.

Before asking for help:

1. read the [installation and verification instructions](README.md#installing);
2. check the [documented limitations](README.md#what-it-cannot-do); and
3. search the repository's existing issues.

For installation, verification, or device-use questions, open a support
request through the repository's GitHub issue chooser. For reproducible bugs,
use the bug-report form. Include the board revision, MicroPython version,
operating system, exact command, and sanitized output where relevant.

**Never post a real seed phrase, BIP39 passphrase, private key, roll sequence,
wallet descriptor, or xpub.** Use published test vectors or clearly disposable
test data. Screenshots and logs can contain wallet material; inspect and redact
them before uploading.

Do not report security vulnerabilities through public support channels. Follow
the reporting instructions in [SECURITY.md](SECURITY.md).
